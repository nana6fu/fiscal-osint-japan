# Fiscal OSINT Japan 記事執筆スタイルガイド

**バージョン**: v1.0 (2026/5/31 作成)
**対象**: シリーズ「日本の財政の真実」全記事および今後の単発記事
**目的**: ブランディングの統一・読者の信頼の継続的な蓄積

---

## サイトの理念(全記事で守る)

1. **一次資料を最優先する** ——個人ブログ・SNS投稿を出典としない
2. **因果関係を断定しない** ——「相関である」「観察される」と書く
3. **両極端を避け、中間地点を提示する** ——リードまたは結論で必ず明示
4. **読者が自分で原典を確認できる動線を作る** ——URLを必ず明記
5. **AIで何ができたかは透明に書く** ——編集後記で
6. **個人名は煽る目的では出さない** ——公的記録に残っているもののみ

---

## 必須構造(全記事共通・順序固定)

1. head 内: title, description, og:title, og:description
2. body > div.container
3. header
   - div.breadcrumb : ← Fiscal OSINT Japan / 記事一覧 / English
   - h1 : メインタイトル<br>— サブタイトル
   - div.sub : サブタイトル本文(記事の核心を一文で)
   - div.meta : series-badge + 公開日 + 字数 + 読了時間
4. div.lead : 3-4段落のリード文(最後の段落で立場・方針を明示)
5. div.toc : 目次(h3 + ol)
6. 章本文 : h2 id="chapN" で N. タイトル 形式
7. div.author-note : 編集後記(任意・推奨)
8. footer : サイト名・シリーズ番号・日付・編集者

## トーン規則

### 因果関係について
- NG: 「要望書のせいで郵政民営化が起きた」
- OK: 「要望書の項目と日本の制度変更には、時間的対応が観察される」
- OK: 「複数の要因の一つとして要望書も関与した可能性は否定できない」

### データの提示について
- NG: 「日本の借金は1,300兆円だ、財政破綻する」(断定的)
- OK: 「財務省公表データでは負債1,473.8兆円、資産778.1兆円」
- OK: 「ここから何が読み取れるか」(読者に判断を委ねる)

### 仮説について
- NG: 仮説をデータで裏付けたかのように書く
- OK: 「以下の仮説を立てた」「データで検証した結果、仮説は外れた」
- OK: 「仮説が外れた事実も同じレベルで記録する」

### 個人名について
- OK: 公的記録(参議院質問主意書・答弁書等)に残る政治家・官僚
- OK: 著書・公開講演がある経済学者の論
- 慎重: 内閣人事局公表の再就職データ(公表されているが、煽る形では使わない)
- NG: SNSでの個人攻撃に使えそうな文脈

## メタ要素のルール

- シリーズ番号: シリーズ「日本の財政の真実」第N号 形式
- 公開日: 2026年MM月DD日 公開(西暦・漢字併用、半角数字)
- 字数: 約N,000字(千の位は丸める)
- 読了時間: 字数÷500-600字/分で算出
- タイトルの絵文字: h1 には入れない(品位を保つ)
- 章タイトルの絵文字: 入れない(目次で番号管理)
- 記事内の絵文字: 視覚的なアクセントのみ。装飾的に乱用しない

## 制作ワークフロー(Claude向けメモ)

1. 必ず最新記事を土台にコピーする(CSSの不整合を防ぐため)
   cp articles/[直近の記事].html articles/_draft/[新記事].html
2. ヘッダー・リード・目次の書き換え(Python heredocで一括処理)
3. 本文の章スケルトン挿入(各章 (執筆中) プレースホルダ)
4. 章ごとに1章ずつ執筆(齋藤さんに章ごとに確認してもらう)
5. 執筆完了後、DeepSeekでファクトチェック(可能であれば)
6. articles/_draft/ から articles/ 直下に移動
7. articles/index.html ハブに新記事カード追加(既存カードと同じ構造)
8. commit & push
9. Xポスト案を3パターン作成(ファクト淡々型・問いかけ型・姿勢明示型)
