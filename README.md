# Fiscal OSINT Japan

公的資金の流れを、公開一次資料から可視化するダッシュボード。

## 概要

国土交通省・デジタル庁・財務省・総務省・防衛省・厚生労働省の調達データ（特別会計・随意契約・アマクダリ構造）を、会計検査院報告・月次Excel・行政事業レビューシート等の一次資料から集計・可視化。

## 実装済み省庁（2024年度・令和6年度）

- 国土交通省：8地方整備局・全国約3.4兆円
- デジタル庁：随意契約949億・アクセンチュア280億・指名停止
- 財務省：本省222億・国税庁KSK250.2億（BIT170億・日立63億）
- 総務省：電波利用料特会728億・PARTNER145.7億（IBM1社応札）
- 防衛省：地方防衛局6,831億

## データソース

すべて公開一次資料（PDF・Excel）から集計。AIによる推測・断定は含まない。

## AI分析

Groq（Llama 3.3）による補助分析機能付き。
