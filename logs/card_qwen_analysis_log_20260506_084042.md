# Fiscal OSINT Japan 個別カードAI分析ログ

## 実装内容
- 個別カードの「調査判断」にQwen深掘り分析を追加
- 既存のルールベース判定は維持
- ルール判定の下に「AI深掘り」欄を追加
- Qwenには案件名、受注者、契約方式、契約額、予定価格、落札率、確認度、理由、確認資料候補、質問候補を渡す
- 架空企業名・架空金額・架空回数を禁止
- 注意書き・免責欄を出力しないよう指示

## 触っていないもの
- 国交省UI構造
- 防衛省UI構造
- カード展開方式
- CSS
- 開示請求テンプレート

## 確認項目
1. 国交省TOP30カードを開く
2. 調査判断ボタンを押す
3. ルール判定が出る
4. AI深掘りがQwen応答に置き換わる
5. 防衛省TOP30カードでも同様に確認
