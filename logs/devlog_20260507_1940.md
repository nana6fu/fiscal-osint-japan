### AIプロンプトの省庁・年度混入バグ修正
**問題：** 2024年度プロンプトが「国土交通省特別会計」とハードコードされており、
デジタル庁・厚労省を開いても国交省のデータが混入していた。

**修正内容：**
```javascript
// 修正前：yr==="2024"で分岐、2024側は「国土交通省」ハードコード
// 2023側は「随意契約落札率97.3%」（国交省の数字）がハードコード

// 修正後：
var yearLabel = yr==="2024" ? "2024年度（令和6年度）"
              : yr==="2023" ? "2023年度（令和5年度）"
              : yr+"年度";
var prompt = "以下は"+yearLabel+"の"+curMinistry.name+"の調達データです。
  この省庁・この年度のデータのみを使って分析してください。
  他の省庁・他の年度のデータは使わないでください..."
```

**効果：** デジタル庁を開いてAI分析すると「デジタル庁2024年度・アクセンチュア」
のみを正確に分析するようになった。国交省・2013年再就職事案の混入が消えた。
